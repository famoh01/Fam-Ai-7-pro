| ไฟล์ | จำเป็น | คืออะไร |

| **`news.json`** | แนะนำ | ข่าวสดชุดล่าสุด 60 ข่าว (เปิดเว็บแล้วเห็นข่าวทันที) |

## 🚀 ลง GitHub ด้วยมือถือ (3 นาที)

1. เข้า **github.com** → ล็อกอิน → **New repository** → ตั้งชื่อ `fam-ai` → **Public** → **Create repository**
2. ในหน้า repo กด **Add file → Upload files**
3. เลือกไฟล์ **`index.html`** (และ `news.json` ถ้าต้องการ) → **Commit changes**
   - ต้องอยู่ที่หน้าแรกของ repo ห้ามสร้างโฟลเดอร์
4. ไปที่ **Settings → Pages**
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` · **Folder:** `/ (root)` → **Save**
5. รอ 1–2 นาที → เปิด `https://ชื่อผู้ใช้.github.io/fam-ai/`

## 🔄 ข่าวสดทำงานอย่างไร

ไล่ลำดับอัตโนมัติ — สำเร็จข้อไหนใช้ข้อนั้น:

1. **`news.json`** — ข่าวชุดล่าสุดที่อัปไปด้วย (เร็วที่สุด)
2. **RSS สด** ผ่าน CORS proxy (rss2json → allorigins) จาก 9 สำนักข่าว
3. **Snapshot ในไฟล์** — ถ้าเน็ต/พร็อกซีไม่พร้อม ก็ยังเห็นข่าวจริงชุดล่าสุด

ป้ายมุมซ้ายจะบอกแหล่งที่ใช้อยู่: `ข่าวสด • news.json` / `ข่าวสดจริง • RSS` / `ข่าวชุดล่าสุด`

รูปข่าวโหลดผ่าน **wsrv.nl** (proxy ที่รองรับ CORS) ทำให้วาดลง canvas และดาวน์โหลดคลิปได้
กดปุ่ม **🔄 รีเฟรชข่าว** เพื่อดึงข่าวใหม่ทันที (หรือรอระบบรีเฟรชเองทุก 3 นาที)

## ⏱️ (ไม่บังคับ) ให้ข่าวอัปเดตเองทุก 20 นาที

GitHub บังคับให้ไฟล์ workflow อยู่ในโฟลเดอร์ `.github/workflows/` เท่านั้น ทำบนมือถือได้:

1. อัปโหลด **`fetch_news.py`** ขึ้น root ก่อน
2. กด **Add file → Create new file**
3. ช่องชื่อไฟล์พิมพ์: `.github/workflows/news.yml`
4. ก๊อปเนื้อหาในไฟล์ **`news.yml`** ทั้งหมดไปวาง → **Commit changes**
5. ไปที่แท็บ **Actions** → กด **Enable workflow**

จากนั้น GitHub จะรัน `python fetch_news.py` ทุก 20 นาที แล้ว commit `news.json` ให้เอง

## 🎬 วิธีใช้สตูดิโอ

1. เลือกข่าวจากฟีด (หรือค้นหา / กรองหมวด / กดรีเฟรช)
2. กด **“✂️ นำข่าวนี้ไปตัดต่อลง Reels”**
3. แก้คำบรรยาย หรือ **“✨ สร้างซับจากพาดหัว”** · เลือกสไตล์ซับ 4 แบบ · เพลง · การจัดภาพ
4. กด **“⬇️ โหลดคลิปลงเครื่อง”** → ไฟล์วิดีโอ 1080×1920 ยาว 10 วิ

> มือถือ: ไฟล์จะถูกบันทึกเข้าคลังไฟล์/Photos — แนะนำ Chrome หรือ Safari เวอร์ชันใหม่
> คอม: แนะนำ Chrome/Edge เพื่อได้ MP4 (H.264) ที่อัปโหลดลง Reels/TikTok/Shorts ได้ทุกแพลตฟอร์ม
